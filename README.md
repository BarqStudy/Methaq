# ميثاق التركيز · Lock-in Duo

تطبيق تليجرام عربي لجلسات تركيز ثنائية. يحدّد كل طرف هدفه، ويبدأ المؤقت الخاضع للخادم بعد موافقة الطرفين على ميثاق الجلسة. تأتي جميع المكافآت من المنصة. تمنح الجلسة المكتملة لكل طرف ٤٥ نقطة إنجاز و١٥ نقطة تعاون. عند الانسحاب تُحرق حتى ٢٠ نقطة من رصيد المنسحب، ويمنح النظام شريكه ٢٥ نقطة صمود.

## التطوير المحلي

يتطلب Node.js 24 أو أحدث. يستخدم الخادم PostgreSQL في Supabase عند ضبط `DATABASE_URL`، ويعود إلى SQLite للتطوير المحلي فقط.

```sh
npm ci
npm test
DEV_GUESTS=1 npm start
curl -fsS http://localhost:3000/health
```

افتح التطبيق في نافذتين مستقلتين لاختبار الجلسة الثنائية. أنشئ غرفة وانسخ رابط الدعوة من غرفة الانتظار ثم افتح الرابط في النافذة الثانية. وافق من النافذتين وجرّب المؤقت أو الانسحاب. يمكنك استعمال `npm run dev` لإعادة تشغيل الخادم عند تعديل الملفات. يبني `npm ci` ملف Tailwind تلقائيًا.

## تشغيل تليجرام

اربط Web App بالبوت من BotFather واضبط عنوان HTTPS العام. يمكن استخدام التطبيق الرئيسي للبوت أو تطبيق باسم قصير. استخدم إعدادات الاستضافة لربط متغيرات الإنتاج.

| المتغير | الاستخدام |
| --- | --- |
| `BOT_TOKEN` | توكن البوت. يحتاج الخادم إلى القيمة الفعلية للتحقق محليًا من توقيع بيانات تليجرام. |
| `BOT_USERNAME` | اسم مستخدم البوت لتوليد روابط الدعوات. |
| `APP_SHORT_NAME` | الاسم القصير للتطبيق عند استخدام تطبيق مسمى. اتركه فارغًا للتطبيق الرئيسي. |
| `PUBLIC_URL` | عنوان HTTPS للتطبيق الذي يفتحه أمر البوت `/start`. |
| `RUN_BOT` | اضبطه إلى `1` لتشغيل أوامر البوت عبر polling. |
| `NODE_ENV` | اضبطه إلى `production` لتعطيل الدخول كضيف. |
| `DATABASE_PATH` | مسار قاعدة SQLite على قرص دائم. الافتراضي `data/methaq.sqlite`. |
| `DATABASE_URL` | رابط Session Pooler من Supabase. عند وجوده يصبح Supabase مخزن الإنتاج الأساسي ويتجاهل الخادم `DATABASE_PATH`. لا تحفظه في GitHub. |
| `PRO_STARS` | سعر عضوية برو لثلاثين يومًا بنجوم تليجرام. اتركه فارغًا لإيقاف الشراء. |
| `SPECIAL_STARS` | سعر عضوية سبيشل مدى الحياة بنجوم تليجرام. اتركه فارغًا لإيقاف الشراء. |
| `PAYMENT_SUPPORT` | نص أمر `/paysupport` ووسيلة التواصل مع صاحب البوت بشأن المدفوعات. |
| `PORT` | منفذ HTTP محليًا. الافتراضي `3000`. |

تستخدم الدعوات داخل التطبيق رسالة تليجرام مرفقة بزر «انضمام». تتطلب تليجرام Mini Apps API 8.0 أو أحدث، ويختار المُرسِل المحادثة من واجهة تليجرام. يمكن أيضًا مشاركة رابط أو رمز الغرفة، أو دعوة شريك باسمه عندما يكون فاتحًا ميثاق.

العضويات عمليات شراء بنجوم تليجرام بدفعة واحدة. عند ضبط أحد السعرين يبدأ استقبال تحديثات الدفع تلقائيًا عبر البوت؛ خصص له نسخة خادم واحدة، وقرص SQLite دائم قبل قبول أي دفعة. الألقاب والشارات المشتراة بالنقاط تدوم ثلاثة أيام. تتيح العضوية تفعيل الألقاب والشارات والثيمات طوال مدة العضوية، مع الألوان الحصرية وجلسات حتى ١٨٠ دقيقة واستراحة واحدة لكل جلسة بموافقة الشريك. بقية العناصر الاستهلاكية متاحة بالنقاط.

شغّل نسخة واحدة من الخادم. تُحفظ الحسابات والمكافآت والمشتريات وسجل الجلسات والغرف الجارية في Supabase، وتُستعاد الغرف بعد إعادة تشغيل Railway. عند غياب `DATABASE_URL` تُستخدم SQLite محليًا. يعتمد الاهتزاز ومشاركة صورة الإنجاز على إمكانات الجهاز، مع إتاحة تنزيل الصورة عند غياب مشاركة الملفات. تستخدم سلسلة الالتزام اليوم حسب UTC.

## لوحة الإدارة

انسخ معرّف حسابك الظاهر في مظهر المنصة ← حالة صلاحية الإدارة، ثم أضف متغير `ADMIN_TELEGRAM_IDS` في إعدادات الاستضافة وضع فيه المعرّف الرقمي. افصل بين المعرّفات بفاصلة إذا كان هناك أكثر من مشرف. بعد النشر أعد فتح التطبيق واضغط **الإدارة** من الشريط العلوي. ابحث باسم الطالب أو بحسابه أو بمعرّفه لتفعيل باقة أو حظر حسابه أو رفع الحظر. أنشئ كودًا لكل طالب واختر برو أو سبيشل. يفعّل الطالب الكود مرة واحدة من صفحة المتجر. تحفظ SQLite العضويات والأكواد والحظر، لذا استخدم قرصًا دائمًا في الاستضافة.

يقدر المشرف إزالة العضوية أو إضافة نقاط لحساب الطالب. إذا سجّل صديق كود الدعوة الشخصي من صفحة الإحصائيات أو انضم عبر دعوة غرفة ثم أكمل أول جلسة له، تُضاف ١٠٠ نقطة له و١٠٠ نقطة لصاحب أول دعوة مرة واحدة.

## Supabase وRailway

أنشئ مشروع Supabase، وانسخ رابط **Session pooler** بصيغة URI إلى متغير Railway السري `DATABASE_URL`. ينشئ الخادم الجداول والفهارس تلقائيًا في أول تشغيل، ويمكن التأكد من الاتصال بفتح `/health` والتحقق من ظهور `"database":"postgres"`. لا تضع كلمة مرور قاعدة البيانات في `.env.example` أو GitHub. الخطة المجانية مناسبة للتجربة، وقد يوقف Supabase المشروع غير النشط وفق سياسة الخطة.
